## Funcion a calcular segun el pedido

Este programa calcula el monto total a pagar por una compra, multiplicando el precio unitario del producto por la cantidad de unidades que lleva el cliente.

## Función

La función 
calcular_total(precio, cantidad)
- Recibe dos valores: precio unitario y cantidad.
- Realiza el cálculo: precio × cantidad.
- Devuelve el total mediante return.
- El bloque principal llama a la función y muestra el resultado en pantalla.
